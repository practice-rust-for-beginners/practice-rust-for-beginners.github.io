## How It Works

Each track follows the same three-phase loop:

<div class="grid" markdown>

<div class="phase-card" markdown>

### :fontawesome-solid-book-open: Learn

Concept explanations, annotated code examples, and mental models — everything you need to understand *why* before you write a line.

</div>

<div class="phase-card" markdown>

### :fontawesome-solid-dumbbell: Practice

Incremental exercises with starter code and expected outputs. Build muscle memory one concept at a time.

</div>

<div class="phase-card" markdown>

### :fontawesome-solid-trophy: Challenges

Harder, open-ended problems that require combining multiple concepts. No hand-holding — just your editor and the Rust compiler.

</div>

</div>

## Prerequisites

!!! tip "What you need to get started"
    - A basic understanding of **any** programming language (Python, JavaScript, Java — anything works).
    - [Install Rust](https://rustup.rs/) via `rustup` — takes 2 minutes.
    - A code editor — [VS Code](https://code.visualstudio.com/) with the `rust-analyzer` extension is recommended.
    - No prior Rust knowledge required. Track 1 starts from zero.
